# PCA9685 Driver API reference {#mainpage}

The classes, members and registers of the HardFOC PCA9685 driver, generated from the headers.

Start with pca9685::PCA9685, the driver, and pca9685::I2cInterface, the interface your platform port implements.
The register map is pca9685::PCA9685::Register and the error flags are pca9685::PCA9685::Error.

The guides, with examples that compile, are on the documentation site: <a href="../">PCA9685 Driver
documentation</a>.
